# JPEG Transmorphing Study

This repository documents my study of JPEG image processing and the concepts needed to understand JPEG transmorphing.

The goal is to build a clear foundation in how JPEG images are represented, compressed and structured before moving into more advanced topics such as reversible image transformations.

## Topics Covered

- Digital image representation
- RGB and YCbCr color spaces
- JPEG compression
- 8×8 image blocks
- Discrete Cosine Transform (DCT)
- Quantization
- Chroma subsampling
- Minimum Coded Units (MCUs)
- JPEG file structure
- JPEG markers and APP markers
- JPEG transmorphing
